📘 JS-Fundamentals
Welcome to JS-Fundamentals, a JavaScript learning project focused on building a strong foundation in JavaScript programming. This repository contains small, focused scripts that demonstrate key concepts and functionalities in JavaScript.

📂 Project Structure
Each file in this repository is a standalone JavaScript script designed to demonstrate a specific concept.

File	Description
0-javascript_is_amazing.js	Prints a string using a constant
1-multi_languages.js	Prints multiple lines using console.log
2-arguments.js	Prints messages based on the number of command-line arguments
3-value_argument.js	Prints the first argument or a default message
4-concat.js	Prints two arguments in a specific format
5-to_integer.js	Converts the first argument to an integer and prints it
6-multi_languages_loop.js	Prints lines using an array and a loop
7-multi_c.js	Prints a string multiple times based on an argument
8-square.js	Prints a square of size x using X
9-add.js	Adds two numbers using a function
10-factorial.js	Computes the factorial of a number using recursion

🛠️ Requirements
Node.js installed on your computer

Basic understanding of command-line interface

🚀 How to Run a Script
bash
Copy
Edit
node <filename.js> <arguments>
Examples:

bash
Copy
Edit
node 0-javascript_is_amazing.js
node 5-to_integer.js 42
node 9-add.js 10 32
📌 Notes
All scripts avoid the use of var; instead, const and let are used.

Input is read from process.argv.

The scripts are meant to be simple and clear for beginners to understand core JavaScript syntax and concepts.
