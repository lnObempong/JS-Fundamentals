### **JavaScript Fundamental Exercises and Projects**


**Overview**
This repository contains JavaScript fundamental exercises and projects designed to help beginners learn core concepts like variables, loops, functions, conditionals, and more.

**Project Structure**
Each file corresponds to a specific task or challenge focusing on a particular concept. Files are named with a prefix number for easy ordering and identification.

**Exercises Covered**
Basic JavaScript syntax and console output

Handling command line arguments

Conditional logic and loops

Functions and recursion

Arrays and iteration

Input validation and error handling

**How to Run**
Clone the repository:
git clone https://github.com/lnObempong/JS-Fundamentals.git

Navigate to the project folder:
cd JS-Fundamentals

Run any JavaScript file using Node.js:
node <filename>.js [arguments]
